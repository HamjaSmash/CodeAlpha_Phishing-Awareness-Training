# Phishing Awareness Training

Part of the CodeAlpha Cyber Security Internship (Task 2).

## About
A presentation and interactive quiz that teach people how to recognise and avoid phishing attacks.

## What's inside
- `Phishing_Awareness_Training.pdf`: the presentation 
- `Phishing_Quiz_Questions.md`: quiz questions, answers and explanations

## Topics covered
- What phishing is and why it works
- Types of phishing: email, spear phishing, whaling, smishing, vishing, fake sites
- Social engineering tactics
- How to spot fake emails and websites
- Real-world examples
- What to do if you clicked
- Best practices (2FA, password managers, never sharing OTPs)
